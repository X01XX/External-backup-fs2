Changes from the UES-Forth project.

Added structs for mask and state.  The structs contain the number of bits they use.

A pn=1 square should be considered changed at the second sample, since it will be incompatible to a,
formerly compatible superset, pn=2 square.
 
Allow union of rules ( 0->0, 0->1 ) ( 1->1, 1->0 ), to make ( XX, Xx) or ( X0, X1 ).

Separate adjacent-incompatible pairs, and possible regions, from non-adjacent-incompatible pairs, and possible regions.
Non-adjacent pairs must be within at least one region calculated from only adjacent-incompatible pairs.
Final possible regions are an intersection of adjacent and non-adjacent possible regions.
No final possible region will contain an incompatible pair of samples.
Final possible regions containing at least one sample, map to a group.

Functions in actionxts.fs return a state result, instead of a sample.  The action will create a sample
from the current state and the result.
